## Design Specificity: authored for this product
Ledger-green-on-paper token system with semantic money colors, tabular numerals, staged honest microcopy, UAE-native content, and a landing trust promise (review-before-commit, reconciliation badges) that the app structurally delivers.

Deterministic scan: source scan 0 findings; in-page runtime scan found 28 across 3 pages — layout transitions (width/height on progress fills + sidebar + body), 10px functional text ("price change" badge, "ET" avatar), ~96–103ch line lengths in landing prose, nested-cards and cramped bottom padding on the transactions container. No user-visible overlay possible (browser harness suppresses console/injection display); findings recovered via DOM bridge.
